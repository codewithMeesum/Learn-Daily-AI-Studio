# LEARN DAILY AI — CONTENT STUDIO

**Local Setup:**
1. `pip install -r requirements.txt`
2. Create `.streamlit/secrets.toml` and add: `GEMINI_API_KEY="your_api_key_here"`
3. Run: `streamlit run app.py`

**Deployment (Streamlit Community Cloud):**
1. Upload these 4 files to GitHub.
2. Connect repo on share.streamlit.io.
3. In Advanced Settings -> Secrets, paste: `GEMINI_API_KEY="your_api_key_here"`
4. Deploy.
